# 受控数据导入与公开基底结构说明

本文只说明数据血缘、合并键和公开边界，不列出条目—编码关联、码名清单、算法参数或内部历史版本号。

## 一、受控输入单元

三个权威数据源分别为 Prolific、见数第一期、见数第2期。每个源在受控研究目录中按以下三层保存：

1. `原始数据/`：平台导出与清洗后的官方量表、人口学和健康结局；
2. `后台导入/`：仅供专有计算引擎使用的受控输入；
3. `后台计算导出/`：引擎直出的四 α、四载体与 H，共九个读数。

公开仓库不包含第 1、2 层的逐人敏感数据，也不包含可用于反推条目—编码关联的文件。

## 二、样本量与合并键

| 数据源 | 有效样本 | 受控合并规则 |
|---|---:|---|
| Prolific | 462 | 清洗表 `submission_id` = 计算导出 `external_profile_id`，462/462 命中 |
| 见数第一期 | 504 | 原始 `作答ID` = 计算导出 `external_profile_id`，504/504 命中 |
| 见数第2期 | 第1批166＋第2批240 | 以受控作答ID按批次、顺序组和题集合并；E3a 166 对，E2 有效配对164对 |

Gold 子样本为 Prolific 中加测 MAIA-2、AAQ-II、DCS、BADS 的 142 人，不表示全部 462 人均加测。

## 三、公开派生基底

公开第二期文件位于 `code/data/derived/`：

- `p3_base_phase2_long.csv`：572 行，即第1批166人×双问卷＋第2批240人；
- `p3_base_phase2_wide.csv`：第1批166人的新旧题配对宽表。

公开处理规则：

- 以不可逆 `participant_token` 替代平台作答ID；
- 删除提交时间戳与不必要的连接字段；
- 删除全部内部逐题字段及其派生分类或计数；
- 仅保留统计复现所需的九个后台直出读数、批次、顺序与版本标签；
- 公开包不包含原始导入分片、专有映射或参数。

## 四、版本与计分边界

对外只使用：第一期问卷与映射 **科研-第一套题**、第二期 **科研-第二套题**、两期共用 **算法v1.1**。原始后台内部标签不进入公开材料。

PHQ-9、GAD-7、MAIA-2、AAQ-II、DCS、BADS 按各自公开规则计分。九个内部读数全部直接取自后台导出；分析层不作重构或复算。

## 五、复现入口

公开数据使用 `code/python/verify_phase2.py` 核验；E3 统计由 `code/python/e03b_phase2.py` 复现。`export_public_l2.py` 与 `sanitize_public_data.py` 以白名单生成或整理公开基底，不修改受控原始数据。
