# 版本三口径说明（对外唯一标准）

## 1. 对外三口径

| 对象 | 对外名称 |
|---|---|
| 第一期问卷与映射（Prolific + 见数第一期，共用） | **科研-第一套题** |
| 第二期新20题问卷与映射（见数第2期） | **科研-第二套题** |
| 算法参数（两期共用，不因新题调整） | **算法v1.1** |

## 2. 使用规则

- 论文、补充材料和公开仓库统一使用第 1 节的三个对外标识，不使用内部流转编号。
- 这些标识仅用于区分数据来源与分析口径，不表示公开题目—编码映射、内部参数或后台实现。
- Prolific 英文队列与见数第一期中文队列共用科研-第一套题和算法v1.1；第二期新题使用科研-第二套题，算法参数标识仍为算法v1.1。

## 3. 公开文件落点

- 论文的研究设计、数据可用性和第二期分析部分使用相同标识。
- 公开基底的 `mapping_version` / `algo_param_version` 字段保存相同对外标识；公开脚本只读取或核验这些标签，不据此重构内部计分。
